# Contribuir a AI Dev CLI

Gracias por contribuir.

## Licencia de contribuciones

Al enviar contribuciones (código, documentación o tests), aceptas que se publiquen bajo **GNU AGPL-3.0-only**.

## Nota sobre despliegues en red

Si distribuyes una versión modificada como servicio (SaaS), debes ofrecer el código fuente correspondiente de esas modificaciones bajo la misma licencia.

## Flujo recomendado

1. Haz fork y crea una rama para tu cambio.
2. Ejecuta pruebas y lint antes de enviar PR.
3. Abre un Pull Request con contexto claro del cambio.
